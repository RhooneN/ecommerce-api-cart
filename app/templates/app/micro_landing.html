🚀 API de Gestion de Panier

Une API REST complète pour gérer les paniers d'achat de vos utilisateurs. Ajoutez, modifiez et supprimez des articles en toute simplicité.

Voir les endpoints Modèles de données

🛒 Endpoints Panier (Cart)

GET
/cart/

Récupère le panier complet de l'utilisateur connecté avec tous les articles, totaux et compteurs.

Réponse 200 : Cart
POST
/cart/add/

Ajoute un nouvel article au panier. Nécessite l'ID du produit et la quantité souhaitée.

Body (JSON) : CartItem
Réponse 201 : CartItem
PUT
/cart/{product_id}/

Remplace complètement la quantité d'un article existant dans le panier.

Paramètre : product_id (integer)
Body : CartItemUpdate
PATCH
/cart/{product_id}/

Modifie partiellement la quantité d'un article. Envoyez uniquement le champ à mettre à jour.

Paramètre : product_id (integer)
Body : PatchedCartItemUpdate
DELETE
/cart/remove/{id}/

Supprime un article spécifique du panier en utilisant l'identifiant de l'item.

Paramètre : id (integer)
Réponse 204 : Pas de contenu
DELETE
/cart/empty/

Vide complètement le panier de l'utilisateur en supprimant tous les articles d'un coup.

Réponse 204 : Pas de contenu

📦 Endpoint Commande (Command)

POST
/command/

Déclenche la création d'une commande à partir du panier actuel. Transforme le panier en commande validée.

Réponse 200 : Pas de corps de réponse

Modèles de données (Schemas)

📋 Cart

Représentation complète du panier

  • id requis lecture seule integer
  • user_id integer (int64)
  • items requis lecture seule CartItem[]
  • total requis lecture seule string
  • items_count requis lecture seule string

📦 CartItem

Article individuel dans le panier

  • id requis lecture seule integer
  • product_id requis integer (int64)
  • quantity integer (min: 0)
  • name requis lecture seule string
  • price requis lecture seule string
  • subtotal requis lecture seule string
  • product_details requis lecture seule string

✏️ CartItemUpdate

Utilisé pour les mises à jour complètes (PUT)

  • quantity integer (min: 0)

🔧 PatchedCartItemUpdate

Utilisé pour les mises à jour partielles (PATCH)

  • quantity integer (min: 0, optionnel)

Tous les champs sont optionnels pour une modification partielle.
